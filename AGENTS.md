# Инструкции для агента

## Проект
Backend интернет-магазина пиццы и напитков.
Задание и требования описаны в файле pet_proekt_ne_trogat.
Этот файл не изменять.

## Перед началом работы
- Прочитай требования нужного этапа.
- Изучи существующие контроллеры, сервисы и тесты.
- Следуй принятой в проекте архитектуре и стилю кода.

## Правила изменений
- Выполняй только текущую задачу.
- Не изменяй посторонний код без необходимости.
- Не перезаписывай изменения пользователя.
- Не добавляй зависимости без необходимости.
- Не коммить секреты и файлы окружения.
- Не создавай коммиты и не отправляй изменения без запроса пользователя.

## API
- Соблюдай существующий формат ответов и ошибок.
- Валидируй входящие данные.
- Проверяй права доступа к защищённым endpoints.
- Используй пагинацию для списков.
- Не возвращай пароли, токены и другие секреты.
- Используй существующий механизм переводов для сообщений.

## Проверка результата
- Добавляй feature-тесты для новой функциональности.
- Проверяй успешные запросы, ошибки валидации и права доступа.
- Запускай тесты и проверки качества, принятые в проекте.
- В конце сообщай, что изменено и какие проверки выполнены.
- Если проверку выполнить не удалось, явно укажи это.
